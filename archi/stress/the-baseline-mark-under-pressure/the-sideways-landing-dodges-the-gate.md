# The sideways landing dodges the gate

`--to` lands the seat's head on a new branch without merging; if the gate
hangs on the local-merge path alone, protected-branch flows ship stale marks
forever — precisely the flows big teams use.

## Attractor

The gate holds only where it is least needed, and every PR-driven project
inherits the failure the gate was built against.

## Resolution

Held by construction, pinned by test: the gate is about the archive the
landing publishes, not the merge direction — it runs before any path, `--to`
included, and the verification names the sideways case explicitly.
