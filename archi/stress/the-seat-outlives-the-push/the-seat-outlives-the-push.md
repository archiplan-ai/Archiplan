# the seat outlives the push

A field incident: a protected receiving branch forced the sideways
landing, the landing retired the seat at once, and the pull request sat
open for days. The code merged, the spec never did, and a cleared
session found no worktree, no row and no memory. This round presses the
seat that must outlive its push — how integration is proven, when work
resumes, and what a stale branch and a pile of build junk do to the
sweep.
