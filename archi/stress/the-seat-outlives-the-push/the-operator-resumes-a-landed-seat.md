# the operator resumes a landed seat

The review asks for a change. The operator returns to the landed seat,
edits, commits. The seat now stands past the sha it landed at, and the
pull request no longer describes what the folder holds.

## Attractor

The sweep proves the old landing integrated and frees a folder that
holds newer work. The record lies about the seat, and the operator
loses the answer to the review.

## Resolution

A landing record describes one sha. The moment the seat's head moves
past it, or the tree carries uncommitted work, the record stops
counting: the row reads as live work again and the sweep passes it by.
Nothing is written to say so — the state is derived from the head and
the tree. Derived `a-resumed-seat-is-live-again`.
