# Two seats edit one plan folder

Two seats carry branches that both touch one plan's folder — task prose here,
scenarios there — and the join lands both.

## Attractor

The plan becomes the one artifact whose merges are feared, and teams fall back
to one-writer-per-plan by convention instead of by registry.

## Resolution

Held — this is the shape's selling point, not its wound: content files merge as
text like stressors do; the one surface that cannot fold — lifecycle — is a
small `state.json` whose conflicts are visible and whose writer race
one-plan-one-worktree already forbids through the registry. The old form merged
as one JSON lump; the new one conflicts only where meaning actually collides.
