# Both forms stand at once

A migration leaves `plan.json` beside the folder — or a merge lands one branch's
legacy file into another's records.

## Attractor

Two truths drift silently apart; which one a verb reads depends on load order
nobody documented.

## Resolution

Held by design, not by luck: coexistence is a load error naming which to keep —
a-plan-is-a-folder-of-records claims it and the implementation pins it with a
test. Ambiguity is refused, never resolved by precedence.
