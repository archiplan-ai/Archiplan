# Cold-start pressure

Thirteenth round, pressing the init design before code exists: v0011 models the
cold start as one create-only emitter behind one verb — no wizard, no force flag,
no state beyond the tree itself. This round hunts what breaks that shape: the
re-run that eats a morning's model, the interrupt that strands a half-made root,
the agent that arrives unbriefed anyway, the manifest that already speaks with its
own layout, the installed briefing drifting from the binary that carries the next
one, and the nested init that quietly shadows every verb below it.
