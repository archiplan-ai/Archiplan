# Hand links still cover

Inference will miss: a function whose name and body share no term with the node it realizes is
real and load-bearing, and an operator who wants the untouched surface covered — the dispatch
table was genuinely useful traceability — must still be able to author it.

## Attractor

Press the escape hatches while the filter and the scoped gate land. A pair capture suppresses is
hand-added with `archi link add <ref> <file#symbol>` and must mint asserted, fold, verify and
repin exactly like any other link — suppression scopes what capture volunteers, never what links
may claim, the same boundary `dark-deltas-are-code` drew for exclusions. An asserted link on an
unpressed ref must satisfy the gate's checklist silently: covered is covered, however the link
was born.

## Resolution

Survives by construction in both layers: the signal filter sits inside capture's minting loop
only — `link add` never consults it — and the gate counts asserted links at Working per ref
without asking where they came from. The checklist prints only for refs that are both unpressed
and uncovered.
