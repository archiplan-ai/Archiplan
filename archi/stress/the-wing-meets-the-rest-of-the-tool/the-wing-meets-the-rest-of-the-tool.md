# The wing meets the rest of the tool

The first round pressed the wing against itself and left it standing on `WorldDoc`
and `DocsCompiler` alone. Everything the wing has to live beside went untouched: the
plan, which already owns a thing it calls a scenario; retrieval, whose ranking reads
the corpus it is given; the seats, where two writers mint the same name on two
branches; and every project that upgrades into a binary that knows a folder the tree
does not have. This round asks whether the wing fits the tool it landed in, or only
fits itself.
