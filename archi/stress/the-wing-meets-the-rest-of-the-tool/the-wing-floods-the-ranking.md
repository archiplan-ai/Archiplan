# The wing floods the ranking

`matching-forgives-the-phrasing` damps a term by its frequency across the corpus
scanned in the same pass, and that pass is now larger by the whole wing. A world fact
is prose about people and their days, written on purpose without the nouns of the
model, so it contributes ordinary English at volume: *work*, *change*, *file*, *run*.
Those are the companion terms that used to decide a ranking. The wing does not add
hits to an architecture query; it changes the statistics that order everybody else's.

## Attractor

The round that produced `the-common-word-floods-the-ranking` comes back through a door
nobody watched. Rankings drift as the wing grows — the same query answers differently
this quarter than last, with no change to the thing being searched for — and the
operator loses the one property retrieval had: the same tree and the same phrase give
the same order.

## Resolution

Held. Every document added to this repository shifts the same statistics — a new
requirement does it too — so the wing is ordinary corpus growth and not a new
mechanism. The property retrieval actually promises survives untouched: the same tree
and the same phrase give byte-identical output, because the frequencies are computed
fresh per query over the tree in hand and never persisted. What bounds the drift is the
size of the wing, and `the-check-counts-the-wing` is already the instrument that reports
it.
