# the address book under stale maps

A field incident: an old session mapped a member to an agent-made
worktree. The session ended. The worktree and the mapping stayed. A
later mint followed the stale address and branched the seat from a
dead feature branch — four foreign commits rode in from birth. This
round presses the address book: rows that outlive their target, and
the escape that must stay open.
