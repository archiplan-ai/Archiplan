# an explicit base rides over a poisoned map

Give the mint an explicit `--base <member>=<branch>` while the address
book still points at a side worktree.

## Attractor

The gate, applied blindly, would block the one user who already did
the right thing — named the base outright — and force a detour through
`repo map` before every mint on a machine with an exotic layout.

## Resolution

Holds by design: an explicit base names the branch, so the checkout's
identity stops mattering for the branch point — the gate steps aside
for that member. The worktree placement still anchors on the repo's
main checkout, so even the bypassed path leaves no nested seats inside
scratch folders.
