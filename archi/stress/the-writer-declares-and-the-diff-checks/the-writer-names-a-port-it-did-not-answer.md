# the writer names a port it did not answer

Declare a port the code does not answer and watch nothing object.

The diff proves that a symbol changed and that the writer named something. It cannot prove
the naming is true. Every check available runs on the wrong side of the claim: the name
resolves against the model, so a real port passes; the symbol exists, so the anchor
resolves; the digests match, so `verify` reads clean. All of it holds for a pair that
answers nothing.

The writer is also the actor with an interest. A wave closes when every changed symbol is
named, so naming the nearest plausible port is the cheapest way out of a refusal, and it is
indistinguishable from care. Today the same wrong pair arrives as a candidate — visibly a
guess, retired by a reader in one command. Under the proposal it arrives asserted.

## Attractor

The journal fills with asserted pairs that read exactly like reviewed ones, and the
distinction between "a machine guessed this" and "a person stands behind this" is gone from
the record. Coverage reports rise. The reverse view — which code answers this requirement —
answers confidently and wrongly, and it is now rendered wherever a reader looks.
