# the writer declares and the diff checks

This round presses a proposal, not the standing design: that the writer of the code names
the spec it answers, and the wave-open diff checks the naming, so that nothing is inferred
from shared words.

The standing design infers. Capture takes each changed symbol, each task claiming its file
and each ref in that task's `## Spec`, and mints a candidate when the two share one word.
The same boolean also decides which refs the gate demands coverage for. A wrong match is
loud and a reader retires it. A missed match is silent and leaves the gate along with the
ref, so the wave closes reporting complete coverage having never asked.

The measurement that opened this round: on the unit that closed an hour ago, the two
functions carrying the whole change drew no candidate at all, while the helper that formats
one diagnostic string drew three — one per caller of the port it sits behind — because the
message contains the word `world` and the refs name `WorldDoc`. Across the tree the journal
stands at 2036 captured candidates nobody has read against 103 confirmed. That is the shape
of the inference: it links what reads alike, not what answers.

The proposal replaces the inference with a declaration. A task's sub-agent writes a file
beside the wave index naming the ports and requirements its code answers. `plan next`
refuses while a task has no file, while a declared name does not resolve, and — the load
bearing half — while a changed symbol is named nowhere. Word matching keeps no authority.
The reverse view, which code answers a claim, is rendered on read and never written into a
spec file.

What this round has to find out is where a declaration is worse than a guess. A guess is
reviewed because it is visibly a guess. A declaration arrives asserted, from the one actor
with an interest in the wave closing, and the diff can only prove that something was
declared — never that the declaration is true. Every stressor below presses that seam, or
the seams the transition opens around it.
