# the sweep folds the symbol the declaration named

Let the cleanup wave fold a helper that a declaration named two waves earlier.

The cleanup wave runs after every task wave and its whole job is to move code: fold a
mechanism written twice, put the body in one place. The declarations were made against the
old shape and are already consumed. So the sweep's ordinary success is a link whose symbol
no longer exists.

This tree has already met the conflict from the other side. The last sweep found the same
expression standing inline six times, could fold it, and did not — because each copy sat
inside a test body a link anchors, and moving a body moves the anchor. The rule that keeps
links still is now the rule that keeps duplication in place, and declarations multiply the
anchors that rule protects.

## Attractor

Either the sweep stops folding anything a declaration touched, which is most of the wave's
work, or every sweep ends in a repin pass whose size nobody predicted. The first makes the
cleanup wave ceremonial. The second makes repin routine, and a routine repin is a rubber
stamp — which quietly grants the permission that `the-declaration-is-true-when-written-and-
false-by-the-next-wave` says must never be automatic.

## Resolution

Accepted, and priced by `a-fold-may-move-a-body-never-an-interface`. The sweep may move code
a declaration named and the repin follows; it may not change what that code offers. The line
is one the tool already computes, since a link pins interface and body apart and the sweep's
own probe reports `body moved; the watched interface holds`.

The consequence kept is the one the attractor named: a repin over a body becomes routine,
and a routine repin is a rubber stamp. We keep it because the opposite failure is silent and
permanent — code nobody may tidy rots in place, and the tool built to keep design and code
together becomes the reason they cannot be brought back together. The first sign the line was
drawn wrong will be a repinned pair that no longer answers what it says.
