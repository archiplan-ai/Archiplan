# the file the model must write is refused for its shape and the wave stops on form

Have the sub-agent write the declaration file slightly wrong and watch the wave stop on
punctuation.

The file is authored by a language model and read by a strict parser. Every record shape in
this tree has already taught the same lesson: a plan bullet that wrapped onto a second line
was refused with a message that restated the grammar and never said the bullet wrapped, and
two rounds of guessing went into it. That was a person reading the refusal. The declaration
file is written by an actor that cannot read a refusal at all — it has already returned.

So the failure lands on the orchestrator, who did not write the file, must repair a format
it did not choose, and has the sub-agent's report as its only account of what the file was
supposed to say.

## Attractor

The format is loosened until it stops refusing: fields become optional, unknown keys are
ignored, a missing section is a warning. Each loosening is locally correct and the sum is a
file that always parses and asserts whatever it happens to contain. The gate survives in
name, having stopped checking anything, and the round that argued declaration is stronger
than inference ends with a declaration nobody validates.
