# Two repos, one path

Every member has a `src/main.rs`, a `Cargo.toml`, a `README.md`. The wave index, capture's
delta, the journal's anchors and the audit's findings all traffic in file paths that now exist
several times over.

## Attractor

Cross-member aliasing: a delta in one member's `src/main.rs` presses refs linked to another's,
capture attributes across trees, and two distinct links fold as one.

## Resolution

Holds by construction: the member is part of the key everywhere a path is one — index keys,
anchors, spans, findings — and the unqualified form is not "any member" but exactly home. The
collision cannot be spelled.
