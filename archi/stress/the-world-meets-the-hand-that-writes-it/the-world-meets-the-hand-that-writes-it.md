# The world meets the hand that writes it

Four rounds pressed the world as a structure and never asked who fills it. The author is
usually an agent, and an agent asked for a condition about the world will produce a
fluent one whether it observed anything or not. The material that would ground it —
an interview, a recording, a ticket in another system — does not live in this tree. The
one rule that keeps a fact from becoming a requirement in costume is written in prose and
enforced by nobody. The agent read surface does not carry the world at all. And on a
greenfield project the world is known before the model exists, while `covers` demands
elements to name.

This round presses the content, not the container.
