# the rot is visible only at the crash

Let the map decay in every way it can: a mapped path deleted, a row
left pointing at a linked worktree by an old binary, a clone that is
not the declared repository, a baseline stranded by a squashed landing.
Then work for a month without running `repo ls`.

## Attractor

Every decay mode surfaces at the worst moment — a mint refusal, a
foreign diff, a merge gate — never before. The operator learns about
each rot from an incident, and the map earns a reputation of a trap.

## Resolution

The one verb everyone already runs is `check`: in a spec that declares
members, it surveys the map and reports the rot as advisory findings —
path missing, linked worktree, remote mismatch with the declared url,
baseline on no branch — each naming its source file and its repair.
The briefing calls the moments: the binary before the spec, the seat
right after its mint. Derived `check-surveys-the-members`.
