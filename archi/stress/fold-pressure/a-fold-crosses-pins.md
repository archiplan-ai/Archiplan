# A fold crosses pins

One writer opens a round against the version both branches share; the other saves first and
opens against the version only their branch has. The branches merge — same slug or not — and
someone folds the two rounds into one by hand, the only fold that exists.

## Attractor

Stressors re-ground against a version they never pressed: the fold moves a round's ground
truth without anyone deciding to.

## Resolution

Broke where it was visible and bent where it mattered. Same slug: the differing `version:`
lines put the markers inside frontmatter and the file dies as a syntax error — loud, but a
bare `E_DOC` naming neither the state nor a verb, and the natural marker-deletion repair picks
a pin for both writers' stressors in one keystroke. Different slugs: `E_SESSION: both open`
names the state well, and then the hand-fold moves stressor files under the surviving
session's pin — affects that name elements absent from that version break loudly, but any
stressor whose terms exist in both versions re-grounds without a sound, and its recorded
outcome now describes pressure against a model it never touched. A fold is only honest
between rounds that pressed the same ground; nothing states the rule, checks it, or refuses
for you.
