# Reformat storm

A formatting sweep rewrites every comment, reflows every `.arch` module and reorganizes the
source files — hundreds of changed lines, zero semantic change.

## Attractor

Every sweep mints a version; the archive fills with noise entries, patches stop reading as
design changes, and pins scatter across meaningless ids.

## Resolution

Holds. Canonicalization strips comments, layout and file organization before hashing, so the
render is byte-identical and the save refuses: probed live this round — `version save` against
the unchanged model answered `nothing to save: the model is unchanged since v0001`. Canonical
bytes differ iff the model differs.
