# Verify cries wolf

A refactor formats, reorders and comment-rewrites half the code tree without changing a single
interface; every linked symbol's source bytes move.

## Attractor

Every link reports drift on every sweep; re-pinning becomes a ritual performed without reading,
and the day real drift arrives it is laundered with the noise.

## Resolution

Holds. Hashes are computed over the canonicalized token stream — comments stripped, formatting
collapsed, trailing commas dropped — so byte churn moves nothing. Kind picks the watched hash:
the indirect links of this round hold through body churn by construction, and only the one
literal link (the canonicalizer itself) alarms on body change — which is exactly its contract.
