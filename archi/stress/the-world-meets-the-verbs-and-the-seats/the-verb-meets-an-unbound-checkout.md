# The verb meets an unbound checkout

Run `world add` in a checkout no worktree binds. Every mutating command in this tool
refuses there and names the seats that stand plus the command that mints one. Nothing in
the world's requirements says the world verb does. `exit-codes-are-the-contract` fixes what
a refusal returns and `refusals-name-the-continuation` fixes what it says, and neither is
named by `one-verb-mints-the-world-fact` — the requirement describes a missing parameter
and says nothing about the checkout.

## Attractor

The verb becomes the one door into the tool that skips the discipline. A fact gets
written on `main`, outside any unit of work, and lands by a hand commit that no worktree
carries — precisely the ungoverned mutation the seat rule exists to stop. The rule is
uniform everywhere else, so the exception is invisible until it is used.

## Resolution

The verb inherits the contract rather than getting an exception: derived
`the-world-verb-refuses-like-the-others`. `add` and `rm` mutate and refuse in an unbound
checkout with the shared exit code and the refusal that names the standing seats; `ls`
reads and runs anywhere. Uniformity is the value — an operator who learned the rule once
should not have to learn where it stops applying.
