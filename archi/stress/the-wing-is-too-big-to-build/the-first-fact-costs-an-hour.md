# The first fact costs an hour

Write one fact. Name the condition in a line. Write the paragraph that says why the
behavior follows. Write what would make it false. Write the Gherkin — full language now,
with a member tag on each scenario and a unique name per scenario because the name is the
address. Resolve `covers` against real element paths. Find a locator for `sources` or accept
being named as ungrounded. Check the paragraph for words that are also element names. Then
author a link per scenario, or the plan that touches this node cannot close.

## Attractor

Nobody writes the second one. The wing's own decisions assume a small corpus read whole, and
the cheapest way to keep it small turns out to be never starting. An operator who has a real
observation puts it in a commit message, or in the intent paragraph where such claims have
always gone, because those cost a sentence. The wing ends up holding the two or three facts
somebody wrote while the machinery was new.

## Resolution

The largest item on the author's list goes: derived `the-grammar-is-a-named-subset`, and
`the-grammar-takes-the-whole-language` is retired. A scenario is now six keywords and a tag,
which a person writes from memory instead of from a reference. The rest of the list stands —
the condition, the killer, `covers`, a locator — because each of those is the thing the wing
is for, and none of them is work a machine could have done. The price is signed in
`the-grammar-stays-small`.
