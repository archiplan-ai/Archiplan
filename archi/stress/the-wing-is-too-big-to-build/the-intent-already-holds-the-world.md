# The intent already holds the world

Read the intent that opened this effort. It states the problem in the world — claims stand
in intents forever because nothing can make them false — and it does so in prose, with no
schema, no verb and no check. That is where every claim about the world in this repository
has lived for twenty-five versions. The wing's own founding argument was that such claims
need a home where they can be killed, and the intent is still there, still accepting them,
still costing one paragraph.

## Attractor

Two homes for one kind of claim, and the cheap one wins every time. A world claim goes in
the intent because that takes a sentence and no verb; the wing gets the claims somebody was
willing to formalize, which is a biased sample of the easy ones. The wing does not replace
the leak it was built to close — it stands beside it.

## Resolution

Accepted. The intent keeps its paragraph and the cheap path stays open, so the wing will
hold the claims somebody chose to formalize while the intents keep the rest. Closing the
leak means editing seventeen standing intents against a rule no check can enforce — whether
a sentence is a falsifiable claim about the world or context for a design is judgement, not
a parse. The sacrifice is signed in `the-intent-keeps-its-paragraph`.
