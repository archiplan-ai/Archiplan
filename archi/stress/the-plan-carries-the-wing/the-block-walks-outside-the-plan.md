# The block walks outside the plan

A fact covers four nodes. A plan holds a task for one of them. The close collects that
fact, because the rule is that a fact covering a node the plan touches joins the block,
and prints a scenario whose steps walk through three nodes nobody in this plan is
building. The exit ceremony asks an operator to verify end to end a path that the plan
never had the parts for.

## Attractor

The ceremony stops meaning anything. The block is latched as displayed because latching
is how the plan closes, and the scenario inside it was unrunnable from the first wave.
After two plans of that, the latch is a keystroke and the block is scrolled past — and
the property the move to the wing was supposed to buy, that the closing block is
executable, is spent before it is used.

## Resolution

The fact joins and the block names the gap: derived
`the-block-marks-what-lies-outside-the-plan`. Admitting only wholly-contained facts was
refused, because facts cross plans by design and that rule would empty the block on most
plans. The mark keeps the ceremony honest both ways: what is verifiable here, and what
waits on another plan.
