# A remint moves the round pin

A post-merge remint re-mints a colliding save while a round is open on the same
id: `stress add` resolves `affects` against a version whose id now names different
content.

## Attractor

Stressors validated against one render silently attach to another; the incidence
matrix inherits the lie.

## Resolution

Held — by content, not id: the closing save stamps `version-hash`, and a moved pin
surfaces as the stale-stamp finding naming `version remint --session`; mid-round,
`stress add` compiles the pinned id through the sealed archive and fails loud if
the id cannot be validated. The window left open is exactly the one every pinned
record shares, and pins-survive-a-remint already owns it.
