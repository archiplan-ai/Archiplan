# anchor-gate

The landing refuses stale member baselines — per-member tip-vs-baseline
pre-flight with the anchor recipe, `--to` included; the mint notes an
auto-base behind the member's branch. The briefing carries the step and the
refusal.

## Stack

- Rust — the repository's standing stack
- cargo test — the repository's standing test harness

## Architecture

- `Seats` — the landing gate and the behind-by-N mint note
- `Seats` realizes crates/archi/src/worktrees.rs
- `Scaffold` — carries the anchor step and the refusal recipe into the briefing
- `Scaffold` realizes skills via include_str
