# member-doctor

The map's decay moves from crash-time to the worklist: `archi check`
surveys declared members — missing path, linked-worktree row, wrong
clone, squash-stranded baseline — and the briefing calls the moments:
the binary before the spec, the member sweep right after a mint.

## Stack

- Rust — the repository's standing stack
- cargo test — the repository's standing test harness
- git remote get-url / branch --contains — the two new probes

## Architecture

- `Members` — the survey grows the four decay probes
- `Members` realizes crates/archi/src/members.rs
- `Cli` — check folds the survey into its report
- `Cli` realizes crates/archi/src/main.rs
- `Scaffold` — the briefing carries the moments
- `Scaffold` realizes skills via include_str
