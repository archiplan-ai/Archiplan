# home-base

A field incident: dependent work forked from the default base, silently,
by a raw git branch in a member repo. The command was never touched, so
the answer is discipline: the briefing makes the mint the only branch
maker, the base a spoken choice, and dependent work a question.

## Stack

- Rust — the repository's standing stack
- cargo test — the repository's standing test harness

## Architecture

- `Scaffold` — the briefing's fork discipline
- `Scaffold` realizes skills via include_str
