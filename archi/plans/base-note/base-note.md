# base-note

The explicit `--base` stays the open escape, but stops being silent:
when the named base does not contain the member's recorded baseline,
the mint says so in one note and continues.

## Stack

- Rust — the repository's standing stack
- cargo test — the repository's standing test harness
- git merge-base --is-ancestor — the containment probe

## Architecture

- `Seats` — the explicit-base arm gains the off-baseline note
- `Seats` realizes crates/archi/src/worktrees.rs
