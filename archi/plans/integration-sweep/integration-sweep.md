# integration-sweep

A protected receiving branch forces the sideways landing, and the
landing used to retire the seat at the push — days before the pull
request merged. The seat now lives until its work is in the receiving
branch, the registry keeps its rows as the record of what a machine
carried, and an integrated folder frees itself silently.

## Stack

- Rust — the repository's standing stack
- cargo test — the repository's standing test harness
- git ancestry and tree diff — the read-only integration proof

## Architecture

- `Seats` — the row state, the landing record, the probe and the sweep
- `Seats` realizes crates/archi/src/worktrees.rs
- `Cli` — close, the listing state, the status pointer
- `Cli` realizes crates/archi/src/main.rs
- `Scaffold` — the briefing of the waiting seat
- `Scaffold` realizes skills via include_str
