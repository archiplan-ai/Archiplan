# Removals preflight the blast radius

A doc removal is a verb that names what breaks before touching disk. A
requirement a plan owns refuses with the owning plans and the release recipe;
a stressor of a closed round refuses outright — the record is sealed history;
a stressor some requirement records as origin refuses with the dependents.
Only an unheld record deletes.

## System Context

Deleting a file is the one doc edit whose damage lands elsewhere: dangling
plan ownership, orphaned origins, an incidence matrix that rewrites the past.
`check` would surface each as a finding after the fact; the verb turns them
into refusals before it — same shape as the seat guard, the list instead of
the wreck. Editing a field in place stays a hand edit by design: the schema
validates every field postfactum and the structure already stands — only
creation and deletion carry blast radius.
