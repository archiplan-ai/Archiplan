# a fork is a spoken choice

The briefing forbids silent forks. The mint is the only branch maker —
never a raw `git` branch, in the home repo or in a member. Before every
mint the agent names the base aloud. New work that builds on an
unlanded unit is one poll question, never the agent's own call:
continue in that unit's worktree, mint from inside it, or land it
first. Before the first wave the orchestrator confirms the ground when
it is ambiguous, and sub-agent prompts forbid branch creation and
switching.

## System Context

A field incident: an agent reasoned that two independent specs mean two
independent code slices, ran `git checkout -b` from the default base in
a member repo, and said nothing. The dependency surfaced later as
missing code. Every guard the tool owns sits behind the mint — a raw
branch walks past all of them, so the rule must live in the briefing.

## Satisfy

`Scaffold` carries the rule in the embedded skills: the mint step of
the archi skill, Step 0 and the sub-agent contract of the implement
skill.
