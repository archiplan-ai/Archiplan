# Candidates carry signal

Capture mints a candidate link only where the delta shows signal for the ref: the ref's surface
terms — node path segments, edge endpoints and payload types, split on case and underscores,
the classification rel's own tokens excluded — must overlap the changed item's symbol path or
canonical body tokens (a file-level item contributes its path terms). Pairs with no shared term
are suppressed, not subtracted: the human render counts them, `--json` lists every one, and a
hand `link add` mints any of them asserted at any time. Touches, decays, retire-subtraction and
leftover reporting are unchanged — the filter sits inside the minting branch and nowhere else.

## System Context

The confirm-or-retire review is the ratchet's quality gate. Replayed from
`issues/capture-mints-a-blind-cross-product.md` at its observed worst: a hub-node wave minted
164 candidates, 158 retired unread — test plumbing × the node's whole surface — and the six
load-bearing pairs were indistinguishable except by prior knowledge. A wall that size trains the
operator to mass-retire, the same skim-past disease the audit's prose wall bred before
`dark-deltas-are-code`.

item's canonical tokens against each spec_ref's terms; `link add`, the fold, verify and the
