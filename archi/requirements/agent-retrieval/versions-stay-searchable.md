# Versions stay searchable

`archi search --at <id>` answers for a whole archived version: elements from the
reconstructed render and doc objects as they stood at that seal, one horizon, every
card labeled by it — the retrieval twin of `read --at` and `query --at`.

## System Context

The archive reconstructs any model version byte-faithfully, but requirements, stress
rounds and sessions have no archived form — their history lives in git, outside
archi's seals. Until the doc tree versions alongside the render, a `--at` over the
full corpus cannot be built honestly, and the almost-right merge of pinned elements
with live prose is the lie `the-archive-answers-yesterday` names.
