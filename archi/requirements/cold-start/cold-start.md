# Cold start

Standing archiplan up in a repository is hand work: the manifest, the source layout
and the agent's briefing are authored from the specs — and the specs alone leave
corners open, so the first hour goes to the write → check → fix loop the strict
schemas were designed to end. One verb should stand a project up whole — manifest,
source dir, a starter module that compiles, the workflow skills and the CLAUDE.md
brief installed where an agent looks first — and be safe to run again on any tree,
because half the directories it meets will already be one.
