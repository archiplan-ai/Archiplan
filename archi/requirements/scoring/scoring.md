# Scoring

Design quality debates run on adjectives — "too coupled", "feels fragile" — and
adjectives don't trend, gate or compare. The spec is a graph, so its quality is
measurable: where the architecture sits between order and chaos, which nodes hoard
coupling, where things braid together unnecessarily, which components carry pressure no
stress round has touched, and which couplings the declared edges never admit. The numbers
must read from the compiled model and the recorded rounds alone — no instrumentation, no
runtime traces — and land where the operator already is: the close of a check, the close
of a round.
