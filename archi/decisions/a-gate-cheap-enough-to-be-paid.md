# A gate cheap enough to be paid

The wave asks that a task in flight has written a declaration file that names something. It
does not ask what, and it does not ask for all of it. A symbol two tasks changed may be
declared by one, by both or by neither, and the record then names one author for work two
people did.

That is a real loss of correctness and it is taken deliberately. The wider rule existed for
one wave: every symbol in the delta had to be named, and every task claiming the file owed
it. Applied to the wave that built it, it demanded thirty entries for two changed files —
three for the code, twenty-seven for tests, test helpers and the string constants inside
them. A test answers no part of the spec and a fixture constant answers nothing at all, so
the rule was asking for a field that does not exist for most of what it asked about.

A gate that expensive is not paid. It is satisfied with whatever silences it, which is worse
than a narrow gate honestly kept: thirty entries of noise read exactly like thirty entries of
care, and the reverse view cannot tell them apart.

What is left standing is the part nothing else covers. Nothing can prove a declaration true,
so the accounting was never going to be enforced — only its presence. The presence is what
the gate keeps.

The first sign this was drawn wrong will be shared work whose record names one author, and
nobody noticing because the record reads complete.
