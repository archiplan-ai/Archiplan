# The old stories migrate by hand

The plans standing today keep their `scenarios.md` and no verb reads it. An open plan
holding one gets a finding; a completed plan gets silence. Nothing converts.

The alternative was a fallback: when the wing collects nothing, read the plan's own file.
It costs no migration and it is wrong for one reason — it puts two mechanisms behind one
word again, days after a round was spent taking them apart. A fallback that fires only on
the empty case is also the case that will be most common for a year, so the old path would
be the live path and the new one the exception.

We take the cost, and it is real work: every open plan's stories have to be read, the
condition under each one named, and a world fact written for it. That naming is the part
no machine can do — it is the whole judgment the wing asks for — so a converter would have
produced facts with an empty `sources` and a sentence lifted from a story, which is
exactly the ungrounded record the count now reports on.
